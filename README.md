# WebGame
This is a webgame made by html css and js. It is a simple shooter game.🔥🔥

A fast-paced 2D space shooter built using HTML5 Canvas and JavaScript. In this game, you control a spaceship that can move freely and shoot incoming enemies from all directions. The goal is to survive as long as possible while destroying enemies, avoiding damage, and building up a high score. The game features smooth controls, rotating aim based on mouse movement, and continuous enemy waves that gradually increase the challenge.🔥🔥

The game includes visual effects like particle explosions, a moving star background, and real-time collision detection for both bullets and enemies. It also has sound effects for shooting, hits, explosions, and background music to make the gameplay more immersive. Simple controls and increasing difficulty make it easy to play but hard to master.🔥🔥
