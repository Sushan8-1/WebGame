# WebGame

🚀 Space Shooter Game

A fast-paced 2D space shooter built using HTML5 Canvas and JavaScript, where the player controls a spaceship and fights endless waves of enemies. The goal is simple: survive as long as possible, destroy enemies, and achieve the highest score.

🎮 Game Overview

In this game, you control a small spaceship placed in an open space environment filled with moving stars and incoming enemies. Enemies spawn from all edges of the screen and continuously move toward the player. Your job is to aim, shoot, and survive.

The game becomes progressively more intense as more enemies appear over time, increasing the challenge and requiring faster reactions and better accuracy.

🕹️ Controls
W / A / S / D → Move the spaceship
Mouse Movement → Aim direction
Left Click → Shoot bullets
💥 Gameplay Features
Smooth 360° spaceship rotation based on mouse position
Continuous enemy spawning from all sides of the screen
Real-time collision detection system
Bullet-based combat mechanics
Health system with game over state
Score tracking system
Particle explosion effects when enemies are destroyed
Animated star background for a space-like atmosphere
🔊 Sound System

The game includes immersive audio effects to enhance gameplay:

Shooting sound when firing bullets
Explosion sound when enemies are destroyed
Hit sound when the player takes damage
Background music for continuous gameplay atmosphere
✨ Visual Effects
Particle explosions on enemy destruction
Moving starfield background for depth
Smooth canvas rendering for real-time animation
Dynamic enemy colors for visual variety
🧠 Technical Highlights

This project is built using core web technologies without any external game engine:

HTML5 Canvas for rendering graphics
Vanilla JavaScript for game logic
Object-based design for bullets, enemies, and particles
Game loop powered by requestAnimationFrame
Collision detection using distance-based calculations
Event-driven input handling
📈 Game Progression

The game naturally increases in difficulty as time passes:

More enemies spawn over time
Faster reaction requirements
Higher pressure survival gameplay
🎯 Objective

Survive as long as possible while destroying enemies and achieving the highest score. The game ends when the player's health reaches zero.
